# UniGrade

เครื่องมือติดตามคะแนนและวางแผนผลการเรียนสำหรับนักศึกษา ใช้งานได้ทั้งบนเดสก์ท็อปและมือถือ

## เปิดใช้งาน

เปิด `index.html` ในเบราว์เซอร์ หรือวางไฟล์ทั้งหมดในโฟลเดอร์เดียวกันบน static hosting เพื่อให้โลโก้และไอคอนติดตั้งแอปแสดงครบ

## สิ่งที่ทำได้

- ติดตามคะแนนรายวิชาและคำนวณ GPA
- ตั้งเป้าหมายเกรด วางแผนงานและกำหนดส่ง
- ดูแนวโน้มผลการเรียนและส่งออกข้อมูล
- บันทึกข้อมูลในเครื่องหรือเข้าสู่ระบบ Google เพื่อซิงก์ข้อมูล

หน้าตาใหม่ใช้พื้นผิวสีทึบและลดการเบลอเพื่อให้การเลื่อนและโต้ตอบลื่นขึ้น รวมทั้งเปิดแดชบอร์ดทันทีหลังเข้าสู่ระบบ
